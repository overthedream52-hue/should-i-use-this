SHOULD I USE THIS / MAC WORKSPACE

내 일에 도움이 될까?

새 도구를 찾아 기록하고, 개선 제안은 내가 승인합니다. 외부 링크는 Aside 앱에서 열립니다.

수집 범위

공개 GitHub 저장소와 README 일부를 수집합니다. 검색 순위·별 개수는 추천 점수가 아닙니다.

내 업무 상황 선택

여기에 적은 내용과 공개 원문만 분석 에이전트에게 전달됩니다. 내 파일·계정은 자동 조사하지 않습니다.

상황을 바꾸면 새 분석이 필요하며 이전 승인은 더 이상 실행 대상으로 제공되지 않습니다.

웹 수집 참고자료

기존 수집기가 가져온 공개 자료입니다. 일부 수집·차단·실패를 구분하며, 공식 제품 근거 확인과 추천 분석은 별도입니다.

명시된 GitHub 저장소를 한 번에 최대 5개 확인합니다. 제품 이름만 있거나 유료 서비스인 자료는 추가 조사 대상으로 남습니다.

발견·분석 기록

수집 → 구독 에이전트 분석 → 제안 → 내 승인. 설치나 결제는 자동으로 실행되지 않습니다.

승인 요청과 기록

범위·비용·검증 방법을 확인하세요. 승인은 아래 제안 범위에만 유효하며, 에이전트의 실제 작업 완료와는 다릅니다.

공유와 보존

다른 로컬 에이전트는 같은 저장소의 jobs / submit / approved 명령을 사용합니다. Google Sheets와 다른 기기 동기화는 아직 연결하지 않았습니다.
