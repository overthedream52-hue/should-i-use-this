## Fact — 공식 문서

1. 구독 경로: `openai_codex`는 개인 ChatGPT 로그인으로 동작하며 개인 구독 한도를 소비한다. API 호출자·공개 방문자 및 문서 이미지 설명 같은 백그라운드 작업에는 제한이 있다. CLI auth.json 재사용 방식이 아니며 토큰 갱신 경합 시 재연결이 필요할 수 있다. 표시 비용은 실제 구독 청구액과 다르다. 이는 AgenticOS 제공자의 구현 설명이며 OpenAI의 제3자 연동 승인이나 사용자 환경 작동을 확인한 것은 아니다.
   https://vstorm-co.github.io/agenticos/models/
2. 운영: Docker Compose와 Postgres/pgvector·Redis·API·worker·console이 필요하다. 사용자가 배포·업데이트·백업·복구·접근권한을 관리한다. 라이선스가 운영·모델·외부 서비스 비용까지 무료로 만들지는 않는다. 정확한 Mac 메모리 요구량은 읽은 문서에서 확인하지 못했다.
   https://vstorm-co.github.io/agenticos/
   https://vstorm-co.github.io/agenticos/rollout/
3. 승인: capability 승인과 MCP binding 승인은 별도다. MCP의 writes는 서버의 read-only 표시에 의존하며 문서는 통제하지 않는 서버에 all을 제안한다. 모델 제공자 내부 실행 도구는 로컬 승인 게이트를 통과하지 않는다. 따라서 설치만으로 모든 실행에 사용자 승인이 보장되지 않는다.
   https://vstorm-co.github.io/agenticos/governance/
4. 데이터: 자체 호스팅이어도 모델·검색·파싱·추적 서비스로 전송될 수 있다. 대화 삭제 후에도 실행 기록의 프롬프트 사본이 남을 수 있고 백업은 별도다. 같은 문서에 정기 보존 삭제가 구현됐다는 설명과 아직 수동 삭제라는 문장이 공존한다. 정확한 릴리스·코드 확인 전 보존 자동화 완료를 확정하지 않는다.
   https://vstorm-co.github.io/agenticos/data-protection/

모두 제공자 자료다. 독립 실측 성능·보안 검증은 수행하지 않았다.
