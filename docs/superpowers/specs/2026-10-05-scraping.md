# 링크 수집과 도입 판단 연결

사용자 승인: 기존 Scrapling 수정본을 재사용하여 Should I Use This에 맞게 구현. 새 크롤러 포크/모델/API 구매 없음. 수정본 위치는 아직 미확인. 정본 프로젝트는 상위 should-i-use-this이고 legacy-research는 보존한다.

공통 수집 패킷 web-collection-v1: 공개 원문 URL, 수집시각, 수집기, 본문, 미디어 URL/대체텍스트 목록, 접근 상태(partial/blocked/failed), 한계 목록. 완전 수집 판정은 하지 않는다. 이미지 주소/alt를 OCR로 간주하지 않는다. 입력 source 역할은 discovery로 고정하며 공식 제품 근거로 자동 승격하지 않는다.

로컬 Python CLI가 현재 Python 환경의 scrapling.fetchers.DynamicFetcher를 호출한다. 사용자가 수정본 환경에서 실행할 수 있으며 코드 복제 없음. 설치·로그인·쿠키 가져오기·OCR·영상 다운로드·유료서비스 호출 없음. Instagram 게시물/릴스와 GitHub 저장소 URL만 첫 버전에서 허용한다. 동적 페이지의 제한된 스크롤과 게시물 내부 Next 이동을 실행한다. 제한/미디어/OCR 부족을 보고한다.

정적 웹은 CLI를 직접 실행하지 않는다. JSON 파일 선택→수집 범위/내용 미리보기→명시 가져오기→기존 자료수집/공식근거 확인 요청에 전달한다. 개인 상황은 유지, 후보 이름은 비우고 게시물 URL을 입력, 이전 결과와 전송동의 무효화. 오류 시 기존 입력 보존. 외부 전송 없음.

성공: 거짓 완료 없이 패킷 검증, 본문·미디어별 확인 한계 보존, UI 가져오기→기존 판단 준비 연결, malformed/oversize/unsafe URLs/blocked/empty/stale async/reset 테스트. 실제 수정본과 Instagram 성공 여부는 별도 실행 증거 없이는 미검증.
